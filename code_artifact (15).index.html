🎯 2. 血糖分级决策与伊那利塞剂量调整原则 (9mg → 6mg → 3mg)

✅ Grade 1 / 正常达标：FPG ≤ 8.9 mmol/L

无需调整伊那利塞剂量。继续饮食运动干预，按原定周期随访。有高危因素者可考虑启动/强化二甲双胍。

⚠️ Grade 2 / 中度升高：8.9 < FPG ≤ 13.9 mmol/L

暂停伊那利塞直至 FPG ≤ 8.9 mmol/L；启动/强化口服降糖药（首选二甲双胍，不推荐优先使用胰岛素）；恢复至≤8.9后同剂量继续。若持续7天 >11.1-13.9 mmol/L，建议咨询内分泌专科。

🚨 Grade 3 / 严重升高：13.9 < FPG ≤ 27.8 mmol/L

立即暂停伊那利塞，排查酮症，当日联系主治医生/内分泌会诊并强化降糖。若≤7天内降至≤8.9，可同剂量恢复；若>7天恢复或30天内再次≥3级，恢复时降低一个剂量水平（9→6mg 或 6→3mg）。

🆘 Grade 4 / 危及生命：FPG > 27.8 mmol/L 或出现 DKA

立即急诊就医并暂停伊那利塞，评估血容量不足与酮症并补液。降至≤8.9后降低一个剂量水平；若30天内再次≥4级，永久停药。
